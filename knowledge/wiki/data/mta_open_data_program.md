# MTA Open Data Program

## Why this matters

This page anchors the project’s relationship to MTA’s own Open Data and Data & Analytics goals. The product should look like a responsible public-data use case, not a random scrape.

## What we know

MTA’s Open Data Program says the agency is committed to transparency and to sharing data publicly. It explicitly values third-party use of data to provide better customer information/service and propose analytical approaches MTA teams can consider.

The page describes the MTA Data & Analytics team as a center of excellence that aggregates data sources, automates analyses, calculates subway and bus performance metrics, maintains critical datasets, and supports executive/front-line/public needs.

The page also provides `opendata@mtahq.org` as a contact path.

## Implementation notes

Use this source in the product README and outreach email to frame the project as:

- Public-data exploration.
- Analytical support / demonstration.
- Source-backed and caveated.
- Open to feedback and correction.
