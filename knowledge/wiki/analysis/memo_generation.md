# Memo Generation

## Goal

Generate route and corridor improvement briefs that combine deterministic metrics with source-backed text.

## Brief sections

1. Executive summary.
2. Route or corridor context.
3. Performance findings.
4. Hotspot map/table.
5. Ridership/rider-impact proxy.
6. Observed reliability/bunching status.
7. Intervention status and evaluation level.
8. Recommended next investigation.
9. Caveats and missing data.
10. Sources, artifact hashes, and source dates.

## Data contract

Brief bodies are generated by `bun run brief-artifacts -- --year YYYY --month M`. The LLM may summarize or restyle those artifacts, but numbers must come from generated JSON, not LLM memory.

```json
{
  "kind": "route_brief",
  "routeId": "M1",
  "month": "2026-03",
  "metrics": {
    "routeScore": 16,
    "averageSpeedMph": 6.7409,
    "hotspotCount": 10,
    "ridershipWeighted": true,
    "totalRidership": 207870,
    "totalTransfers": 40500,
    "scheduledPairCount": 14,
    "scheduleMatchedHotspotCount": 10
  },
  "ridershipProfile": {
    "peakRidershipWindow": {},
    "topRidershipWindows": [],
    "slowCrowdedWindows": []
  },
  "speedProfile": {
    "directionProfiles": [],
    "daypartProfiles": [],
    "slowestDayHourWindows": []
  },
  "interventionStatus": {
    "aceRouteMatched": false,
    "aceActiveDuringAnalysisPeriod": false,
    "aceViolationCount": 0,
    "busLaneMatchedLaneCount": 228,
    "busLaneMatchedStreetCount": 19
  },
  "observedReliability": {
    "status": "insufficient_gtfs_rt_samples",
    "sampleCount": 0
  },
  "scheduleComparisons": [],
  "topSegments": [],
  "sources": [],
  "caveats": [],
  "artifacts": {
    "contentType": "application/json",
    "sha256": "..."
  }
}
```

Every brief should preserve method status. Descriptive before/after comparisons must not be worded as causal claims, and insufficient GTFS-RT coverage must be explicit rather than omitted.

## Tone

- Analyst memo, not marketing copy.
- Plain-language caveats.
- No official endorsement language.
- Clear distinction between "computed by this project" and "claimed by MTA source."
