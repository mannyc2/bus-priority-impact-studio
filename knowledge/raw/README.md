# Raw Source Layer

This directory stores immutable source captures and source metadata.

## Subdirectories

- `downloads/` — downloaded CSVs, PDFs, GTFS zips, or data dictionaries.
- `metadata/` — JSON metadata and schema probes.
- `notes/` — manual notes from source pages or source-reading sessions.
- `assets/` — local images from clipped articles or diagrams.

## Rule

Do not rewrite source captures. If a source changes, add a new dated capture.
