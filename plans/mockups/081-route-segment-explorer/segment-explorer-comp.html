081 comp — Route page: Slow segments & Riders round 4 · 2026-07-18 · all numbers are real B41 serving data (2026-03 release)

One segment surface, an honest map, and a Riders tab with rider data

A + C ship together — they are not alternatives. Exhibit A is the Slow-segments tab and Exhibit C is the Riders tab of the same route page; approving both is the expected outcome of plan 081. Each exhibit now renders its entire tab in page order (round-2 request) so the design can be gauged in context.

Round 2 changes (operator feedback, same day):
  • Readout rebuilt on fixed slots — identical layout for overview / preview / pinned; only values change. The "route-level facts" block is deleted (treatments stay on the Treatments & history tab where they already live).
  • Raw URL text is gone — sharing is a Copy link button in the readout actions; the URL state stays under the hood.
  • Table shows 8 rows by default with "Show all 16 segments"; the lane column is deleted (its yes/partial/minimal taxonomy explained nothing — lane presence now lives on the map layer and as one plain readout line).
  • "Highest-impact segment" KPI tightened: fact + a two-word Map › link, no sentence.
  • "When riders ride" legend deleted — the on-chart flag and the card subtitle carry it. Speed-by-hour legend trimmed the same way.
Round 4 changes (operator feedback, same day):
  • Painted lanes, third treatment. Round 3's blurred glow band was rejected. Now: the DOT geometry draws as a solid green underlay a few px wider than the route line, sandwiched between the white casing and the speed-colored line — laned stretches get a crisp green rim; where a lane street diverges from the route it reads as its own thin solid line. No dashes (fixed-pixel at every zoom per the MapLibre v5 spec), no blur. One layer: solid line-color, zoom-interpolated line-width, round caps.
  • Kept from round 3: the toggle renders only when DOT lane geometry exists near the route (34 of 350 routes have none) and is labeled "Painted bus lanes (DOT)".
  • Readout header follows the card title/description pattern — same anatomy as "Slowest segments / Ranked slowest first…": a standard title with a one-line description under it that changes by state ("Pin a segment for its 36-month speed history." → "Previewing — click to pin." → "Pinned — Esc or Clear selection to release."). The mono eyebrow label is gone.

D10The readout never shifts. Same five slots — label, segment line, three stats, severity strip, history — for route overview, hover preview, and pin alike; only the numbers swap. Lane presence is one plain line ("Along a DOT bus-lane street for most / part / a little of this stretch"), not a column of jargon.
D11Share is a button. Pinning still writes durable spine-ID URL state for deep links, but the UI never prints a query string — Copy link in the actions row does it. Segments without a stable spine ID get a disabled button, not a fabricated link.
D3Eight rows, then opt-in. The table defaults to the eight slowest with "Show all 16 segments" (pinning something deeper auto-expands). Columns are down to five — the lane column is gone, ACE/TSP chips and per-row hour strips stayed gone from round 1.
D5No treatment prose in the explorer. The route-level facts block is deleted. ACE/TSP remain where they already live — the Treatments & history tab and the data notes; the only treatment on this surface is the opt-in DOT lane geometry.
D2Click keeps focus. Hover previews (map and table mirror), click or tap pins and holds the readout, Esc or Clear releases. No auto-chosen "focus segment" pretending to be a selection.
D4Same attention grammar as /map. Under-7 ember, 7–8 sienna, ≥8 baseline ink, one self-labeled legend strip with live counts; feature-state hover; bounded height; cooperative gestures.
D12Lanes are a solid rim, not dashes or glow. The DOT geometry draws as a solid green underlay slightly wider than the route line — a laned stretch reads as a rimmed line , and where the lane street leaves the route it reads as its own thin solid line . One MapLibre layer: solid color, zoom-interpolated width, round caps. Toggle appears only when lane geometry exists near the route, labeled "Painted bus lanes (DOT)". Green, not NYC's terracotta paint — terracotta would collide with the ember/sienna attention scale.
D13Readout header = card grammar. Title + one-line description, exactly like every SectionCard ("Slowest segments / Ranked slowest first — …"). The description carries the state: "Pin a segment for its 36-month speed history." → "Previewing — click to pin." → "Pinned — Esc or Clear selection to release." No mono eyebrow, no layout shift.
Consistency: the /map network layer currently draws lanes as fixed 1.5px dashes (line-dasharray [3,4]). Adopting this same solid-underlay treatment there is an 080 amendment candidate — one lane grammar on both maps.
